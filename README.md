# Milo for Android

[Download Milo 1.1.0 APK](https://github.com/moozzy26/milo-android-installer/releases/download/v1.1.0/Milo-1.1.0.apk)

**No ChatGPT or GitHub account is needed to download or use Milo.** This repository contains the public installer and instructions only, with no personal records or signing keys.

1. Open the download link on your Android phone.
2. Open `Milo-1.1.0.apk` from Downloads and tap **Install**. Allow installation from your browser if Android asks.
3. Launch **Milo** from your app drawer. You do not need to open a website to use it.

If Milo is already installed, install over it to preserve its records; do not uninstall it first. This is the same signed 1.1.0 release with a new download location.

Milo includes reminders, lists, saved places/directions, daily money entries, monthly budgets and savings goals, planned income, unpaid gigs, partial payments, and English voice commands with review before saving. Records stay on your phone unless you export/share a backup. Maps opens an external map app/browser. Speech uses your phone's speech input service, which may process audio online. Milo stores no audio.

Requires Android 7 or later. Enable notifications and precise alarms in Milo Settings. Download `SHA256SUMS.txt` from the release to verify the APK.
